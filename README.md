Project Overview
This project is a responsive website built using Bootstrap 5 components, featuring 3 fully functional pages. The goal was to explore Bootstrap's official examples, remix components creatively, and deliver clean, modern, and responsive web pages.

 Features
Pages Included:
Home Page (index.html)

Responsive navbar with toggle menu

Hero/Jumbotron section with call-to-action

Feature cards with hover effects

Testimonial carousel

Multi-column footer

About Page (about.html)

Team introduction section

Services showcase with icons

Team member cards with images

Consistent branding throughout

Contact Page (contact.html)

Complete contact form with validation

Contact information cards

FAQ accordion section

Embedded Google Map

Business hours display
